# Rephrasing-Clickbait-Headings-in-Russian-Using-Reinforcement-Fine-tuning-of-Large-Language-Models
The repository provides viewers with some code of data collecting and creating a clickbait paraphrasing systems 

## Some examples:

- original headline:
```
В это трудно поверить: москвичка 9 лет получала пособия на придуманную дочь
```

- generated headline:
```
В Москве 9 лет получали пособия на несуществующую дочь
```
